# Nyansa forecasts

What the Nyansa app downloads, refreshed every four hours:

- `snapshot.json`: forecasts for upcoming matches, sure bets, tables and the record
- `report.json`: the walk-forward backtest
- `history/predictions.json`: every forecast published before kick-off, graded after

Match results, statistics and odds come from [football-data.co.uk](https://www.football-data.co.uk). Forecasts are probabilities, not guarantees. 18+.
